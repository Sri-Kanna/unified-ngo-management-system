# Unified NGO Management System (UNMS)

UNMS is a modern, responsive, and secure full-stack web application designed for **A K Social Welfare Trust** to streamline community connect programs, donation accounting, resource inventory, and volunteer coordination.

---

## 🌟 Key Features
- **Centralized Dashboard**: Live telemetry metrics and data charts (Recharts) covering donations, inventory levels, volunteer engagement, and beneficiary growth.
- **Glassmorphic Apple/Stripe-style UI**: Elegant dark & light modes, custom scrollbars, and fluid animations.
- **Full Localization (English & தமிழ்)**: Instantly switch between languages with saved choices in local storage.
- **Digital Beneficiary IDs**: Automatic QR Code generation for beneficiary cards to speed up checks during welfare distribution programs.
- **Welfare Inventory with Barcodes**: Barcode renderers for inventory items with low-stock and out-of-stock warning statuses.
- **Secure Authentication & RBAC**: JWT login guard paired with strict Role-Based Access Control (Admin, Staff, Volunteer) and complete security audit trail logs.
- **Dynamic Report Exporter**: Single-click database compiler that formats and downloads records as CSV sheets.

---

## 🛠️ Technology Stack
- **Frontend**: Vite, React.js, TypeScript, Tailwind CSS, React Router v6, Axios, Recharts, Lucide React
- **Backend**: Node.js, Express.js, TypeScript, Helmet, CORS, Express Rate Limiter
- **Database & ORM**: PostgreSQL, Drizzle ORM
- **Authentication**: JWT (JSON Web Tokens), cookies, bcrypt password hashing
